# Security

Please report security problems privately, through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**, or use [this link](https://github.com/southsidedean/self-hosted-gitlab-libvirt/security/advisories/new). Please don't open a public issue.

Say what the problem is, how to reproduce it, and which version you use.

Fixes go into the latest version of the tutorial. This is a home lab tutorial, not a hardened product, and anyone who can run jobs on your runner is running code on your machine.
